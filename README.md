# Yang She · Academic Homepage

[**Open the live website**](https://sheyanggg.github.io/)

Yang She is a Ph.D. candidate at Beijing Institute of Technology working on computational welding and scientific machine learning. This repository contains the source files for his academic website.

## Browse the site

- [About](https://sheyanggg.github.io/about.html) · Research interests, education, and technical skills
- [Projects](https://sheyanggg.github.io/projects.html) · Research projects and individual project details
- [Publications](https://sheyanggg.github.io/publications.html) · Papers and links to their publisher pages

## Local preview

From the repository root, run `python3 -m http.server 8000` and open [localhost:8000](http://localhost:8000/). GitHub Pages publishes the site from the root of the `main` branch.
